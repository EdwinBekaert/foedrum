# The plugin

The Claude Code plugin lives in `plugin/`: Markdown skills only, one per `/foedrum:<command>`, with this repository as its marketplace ([ADR 0125](../../adr/0125-the-foedrum-plugin-is-markdown-skills-that-run-the-terminal-with-via-plugin.md)).
How users get it: [delivery](../delivery.md).
The plugin's skills run the terminal with `--via plugin`, which every command of the registry takes (`plugin` or `terminal`): it changes the surface its events record, never what a command may do.
The plugin carries `brew`, `mash` ([ADR 0232](../../adr/0232-foedrum-mash-routes-an-issue-to-the-innkeeper-whose-question-the-answer-chooses-the-recipe-by.md)), `order` and `recipe` ([ADR 0240](../../adr/0240-order-and-recipe-work-by-the-brewery-issue-on-both-surfaces.md)), `status`, `stuck`, `brewers`, `lenses`, `answer`, `resume` and `init` ([ADR 0159](../../adr/0159-foedrum-brewers-reports-each-brewer-s-attempts-outcomes-stuck-batches-and-tokens.md) for `brewers`, [ADR 0221](../../adr/0221-foedrum-lenses-reports-each-lens-s-findings-their-ends-and-its-tokens.md) for `lenses`, [ADR 0212](../../adr/0212-foedrum-init-takes-every-answer-as-an-option-and-foedrum-init-asks-them-in-a-session.md) for `init`, which asks init's questions one run at a time); every other command is marked `terminalOnly` with its reason in the registry, and a parity test (`test/unit/plugin-parity.test.ts`) fails on a command with neither a skill nor a mark (ADR 0125).
How `/foedrum:brew` drives a batch, and opens an interactive step's session in a new terminal window: [foedrum brew and the plugin](brew.md).
