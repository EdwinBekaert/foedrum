# quiz's commands

Each command is `node src/cli.mjs <command> <file> ...`, where `<file>` is the night's quiz file.

| Command | What it does |
|---|---|
| `add <file> <team> <points>` | Adds a score: the points `<team>` got in a round. |
| `teams <file>` | Lists the teams that have a score, once each, in the order they first scored. |

This page is the one list of quiz's commands: a command it does not list does not exist.
